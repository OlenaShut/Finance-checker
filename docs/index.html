Результат

Git створює нову гілку та одразу перемикається на неї. Всі зміни Codex відбуватимуться тут.

Переваги

  • Зміни ізольовані від основного коду
  • main залишається стабільною
  • Можна експериментувати без ризику
  • Легко відхилити невдалі зміни
💡 Усі зміни, які створюватиме Codex, виконуватимуться в окремій гілці.
